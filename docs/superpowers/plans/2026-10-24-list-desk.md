# List Desk Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** At 1024px and wider, the list page becomes a two-pane desk: the list with a floating
composer on the left, and a side sheet with Butler above Notes on the right. Phones and tablets stay
exactly as they are.

**Architecture:** `ListPage` branches on `useMedia(WIDE)`. The items, Butler and notes content
become three render nodes that both branches place (tabs below 1024px, panes at 1024px and up). The
trip desk's app-shell and composer rules move out of `trips.css` into a shared `desk.css` that both
pages import, along with a shared `useComposerBox` hook and a generalized `useAddBarShortcut`. A
small `useRowKeys` hook adds row keyboard navigation on the desk.

**Tech Stack:** React 18, TypeScript, Ant Design `List`/`Input`, dnd-kit, Vitest + Testing Library + MSW.

**Spec:** `docs/superpowers/specs/2026-10-24-list-desk-brief.md`

## Global Constraints

- Desk breakpoint is `WIDE` = `(min-width: 1024px)` from `components/ui/useMedia.ts`. No 1200px breakpoint for lists.
- Below 1024px the rendered DOM of `ListPage` is unchanged (same tabs, `SlipStack` pile, bottom `AddItemBar`).
- Side pane width: new token `--side-col: 340px` in the `:root` block of `styles.css`; run `pnpm design:sync` after.
- Desk rows: `min-height: var(--control-lg)` (44px) instead of `--row-h` (52px). Stamps keep their existing container-query behaviour.
- Only tokens in CSS (no raw hex, px font sizes or numeric weights); `designTokens.test.ts` scans the CSS files it lists, so `desk.css` must be added to that list.
- No new Ant `Card`/`Button`/`Modal`; panels are `Paper`, buttons are `Button`.
- Copy, exact: Butler part heading "Butler"; empty line "Nothing due yet."; Notes part heading "Notes". All other copy is existing.
- Notes keep the manual Save key (no autosave).
- Commits: Conventional with scope, e.g. `feat(list-desk): …`, `refactor(desk): …`, ending with the `Co-Authored-By` line.

## Review Focus

1. **Resize across 1024px with unsaved notes.** Notes typed in the desk pane must survive switching to the tab layout and back (state lives in `ListPage`, not in the pane). Test in Task 4.
2. **Shortcuts while typing.** `/`, `n`, Space, Delete and Backspace in the notes textarea, the composer or an inline row edit must type, never trigger. Tests in Tasks 1 and 5.
3. **Leaving the page restores window scroll.** The `html.desk-shell` class must be removed on unmount and when the window narrows below 1024px, or every other page is stuck unscrollable. Test in Task 4.
4. **Butler off.** House `autopilot_mode: 'off'` hides the Butler part entirely, with Notes filling the pane. Test in Task 4.
5. **Deleting the focused row by keyboard.** Focus moves to the next row (or the previous one if it was last), not to `body`. Test in Task 5.
